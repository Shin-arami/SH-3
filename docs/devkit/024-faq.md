# 2. General Questions


---

## Q1. What is SH-3 DevKit?


Answer:


SH-3 DevKit is a production-oriented AI development framework providing:



Project Generation

Architecture Management

Validation

Extension Support



It provides the foundation for building SH-3 based systems.


---

## Q2. What is the main design philosophy?


Answer:


SH-3 DevKit follows:



Everything Event Driven

Everything Replaceable

Everything Typed

Everything Testable

Supported:



Python >=3.12

# 3. Installation Questions


---

## Q4. How do I install SH-3 DevKit?


Answer:


Development installation:


```bash
pip install -e ".[dev]"

Production installation:

pip install sh3dev
Q5. How do I verify installation?

Run:

sh3dev --version

Expected:

SH-3 DevKit x.x.x
Q6. The command is not found.

Check:

Virtual Environment

PATH

Package Installation

Verify:

python -m sh3dev --version
4. CLI Questions
Q7. How do I see available commands?

Run:

sh3dev --help

or:

sh3dev list
Q8. How do I create a project?

Run:

sh3dev init ProjectName

Generated:

ProjectName/

foundation/

runtime/

services/

kernel/

docs/

tests/
Q9. How do I validate a project?

Run:

sh3dev validate

Example result:

Structure: OK

Documents: OK

Status: SUCCESS
Q10. How do I build artifacts?

Run:

sh3dev build
5. Architecture Questions
Q11. What architecture does SH-3 use?

Answer:

SH-3 uses a layered architecture:

Foundation

↓

Infrastructure

↓

Runtime

↓

Services

↓

Kernel

↓

Deployment
Q12. Why are layers separated?

Answer:

To provide:

Replaceability
Testability
Maintainability
Clear dependencies
Q13. Can a lower layer depend on a higher layer?

No.

Dependency direction is:

Higher

↓

Lower

Reverse dependency is prohibited.

7. Plugin Questions
Q17. Can I create plugins?

Yes.

Plugins use:

PluginProtocol

Registry

Manifest
Q18. Are plugins trusted?

No.

Plugins are treated as:

Untrusted Components

They require validation.

Q19. What can plugins provide?

Examples:

Commands

Generators

Tools
8. AI Extension Questions
Q20. Does SH-3 support AI extensions?

Yes.

AI extensions include:

Agents

Tools

Models

Cognitive Services
Q21. Can AI modify the core system?

No.

AI components must use:

Official APIs

Protocols

Extension Points
Q22. How are AI extensions validated?

Validation includes:

Manifest Check

Protocol Check

Security Check

Test Check
