Version: 1.0.0
Status: Architecture Specification
Category: Cognitive Intelligence Layer

---

# 1. Overview

The SH-3 Cognition Layer defines the architecture responsible for
understanding goals, planning actions, making decisions, and improving
cognitive processes.

The Cognition Layer transforms semantic intelligence into purposeful
behavior.

Core model:

```text
Semantic Intelligence

        ↓

Understanding

        ↓

Planning

        ↓

Decision

        ↓

Action Strategy

        ↓

Reflection
```
